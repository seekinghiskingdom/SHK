Admin Dashboard

Site moderation and management tools for admins and moderators. Admins can configure global thresholds and behavior; moderators have a read-only view.

Checking your access…

Global moderation settings

These settings control how reporting and moderation behave across the site. Changes apply immediately for all users.

When enabled, all new testimonies or similar posts enter the review queue before they can appear publicly. Useful for launch or “lockdown” mode.

Number of unique user reports needed before a post is automatically hidden pending review. Default is 2.

When enabled, moderators can approve flagged content so it returns to public view without an admin re-check. When disabled, admins must give final approval.

When enabled, moderators can mark content as a violation that routes to admins for strikes and penalties. When disabled, only admins can apply violation decisions.

When enabled, users can choose to hide stories marked as sensitive (for example, involving trauma, abuse, or similar topics). Content may still exist, but can be hidden for users who opt out.

Lifetime violation count after which an account is marked for permanent ban (subject to final admin review). Default is 7.

Used for rolling-window checks (e.g., 3 violations in 30 days → short suspension). Exact thresholds and durations are configured elsewhere but use this window.

Moderation queues, account strike views, and other tools will appear here as they are implemented in later phases.
