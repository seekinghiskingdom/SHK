GUIDES FOR BIBLE TOOLS -AI

THESE GUIDES FOCUS ON READING, STUDYING, AND EXPLORING SCRIPTURE THROUGH DIFFERENT TOOLS OR MODES ON THIS SITE. -AI

READING SCRIPTURE IN THE BIBLE HUB (BASIC) -AI

  1. NAVIGATE TO THE BIBLE HUB PAGE: OPEN BIBLE HUB -AI
  2. CHOOSE A TRANSLATION OR LANGUAGE FROM THE OPTIONS PROVIDED. -AI
  3. SELECT A BOOK, CHAPTER, OR PASSAGE RANGE USING THE AVAILABLE CONTROLS OR LINKS. -AI
  4. SCROLL THROUGH THE TEXT, USING ANY BUILT-IN HEADINGS OR VERSE MARKERS TO KEEP YOUR PLACE. -AI
  5. USE THE NAVIGATION CONTROLS OR LINKS TO MOVE TO THE NEXT OR PREVIOUS CHAPTER AS NEEDED. -AI

FUTURE EXPANSION: ADD SCREENSHOTS OR A DEDICATED “HOW TO READ SCRIPTURE HERE” GUIDE PAGE WITH VISUAL CALLOUTS. -AI

USING LANGUAGE & STRONG’S RESOURCES (OVERVIEW) -AI

  1. START AT THE BIBLICAL LANGUAGES PAGE: OPEN BIBLICAL LANGUAGES PAGE -AI
  2. CHOOSE THE LANGUAGE YOU WANT TO EXPLORE (HEBREW, GREEK, OR ARAMAIC, WHERE AVAILABLE). -AI
  3. FOLLOW THE LINK TO THE CORRESPONDING STRONG’S INDEX (FOR EXAMPLE, GREEK OR HEBREW STRONG’S INDEX). -AI
  4. USE THE INDEX TO BROWSE OR SEARCH FOR WORD ENTRIES AND CONNECT THEM BACK TO SCRIPTURE PASSAGES. -AI

FUTURE EXPANSION: CREATE SEPARATE “HOW TO USE STRONG’S INDEX” GUIDES FOR EACH LANGUAGE, WITH EXAMPLES OF LOOKING UP A WORD. -AI

GUIDES FOR DAILY TOOLS & GAMES -AI

DAILY TOOLS AND GAMES ARE MEANT TO BE LIGHTWEIGHT WAYS TO ENGAGE SCRIPTURE, PRACTICE, OR REFLECTION ON A REGULAR BASIS. -AI

USING THE DAILY TOOLS PAGE (OVERVIEW) -AI

  1. OPEN THE DAILY TOOLS PAGE (WHEN AVAILABLE) FROM THE MAIN NAVIGATION OR HOME PAGE. -AI
  2. REVIEW THE DIFFERENT SECTIONS (SUCH AS DAILY VERSE, TRIVIA, MINI-GAMES, OR PRACTICE PROMPTS). -AI
  3. CLICK INTO ANY SECTION TO SEE THE CURRENT DAY’S CONTENT. -AI
  4. LOOK FOR LINKS THAT LET YOU VIEW PREVIOUS DAYS, IF THAT FEATURE IS ENABLED. -AI
  5. USE EXPORT OR SAVE OPTIONS (IF PROVIDED) TO KEEP TRACK OF PROGRESS OR FAVORITE ITEMS. -AI

GENERAL PATTERN FOR GAME-LIKE TOOLS -AI

  1. START FROM THE TOOL OR GAME’S MAIN PAGE OR TILE ON A HUB. -AI
  2. READ THE SHORT DESCRIPTION NEAR THE TOP TO UNDERSTAND THE GOAL OF THE GAME OR TOOL. -AI
  3. LOOK FOR ANY “HOW TO PLAY” OR “HELP” LINK OR ICON NEAR THE CONTROLS. -AI
  4. TRY A ROUND OR SAMPLE INPUT, THEN ADJUST YOUR APPROACH AS YOU UNDERSTAND THE PATTERN. -AI
  5. IF SOMETHING IS UNCLEAR OR SEEMS BROKEN, VISIT THE TECHNICAL HELP OR FEEDBACK PAGES TO REPORT IT. -AI

GUIDES FOR LITERATURE & RESOURCE HUBS -AI

THESE GUIDES EXPLAIN HOW TO MOVE THROUGH LITERATURE AND RESOURCE HUBS WITHOUT GETTING LOST, AND HOW TO USE THEM AS STARTING POINTS FOR DEEPER STUDY. -AI

NAVIGATING THE LITERATURE HUB -AI

  1. GO TO THE MAIN LITERATURE PAGE: OPEN LITERATURE HUB -AI
  2. REVIEW THE MAIN TILES OR SECTIONS (SUCH AS BIBLE, HISTORICAL WRITINGS, DEVOTIONALS, BIBLE STUDIES, AND OTHER GROUPS). -AI
  3. CLICK A TILE TO ENTER THAT SECTION’S HUB OR MAIN PAGE. -AI
  4. USE ANY IN-PAGE NAVIGATION OR TILES TO REACH SPECIFIC SUBPAGES (FOR EXAMPLE, CREEDS, CHURCH FATHERS, OR SPECIFIC DEVOTIONAL CATEGORIES). -AI
  5. WHEN YOU WANT TO GO BACK UP, USE THE BROWSER BACK BUTTON OR THE SITE’S BREADCRUMBS AND LEFT-SIDE NAVIGATION CTA (IF VISIBLE). -AI

NAVIGATING THE RESOURCES HUB -AI

  1. GO TO THE MAIN RESOURCES PAGE: OPEN RESOURCES HUB -AI
  2. LOOK FOR CATEGORIES SUCH AS ONLINE RESOURCES, CHILDREN’S RESOURCES, MINISTRY RESOURCES, OR OTHER THEMATIC GROUPS. -AI
  3. SELECT A CATEGORY TILE TO SEE RELEVANT LINKS, DESCRIPTIONS, AND SUBPAGES. -AI
  4. FOLLOW SPECIFIC LINKS TO EXTERNAL SITES WHEN PROVIDED, KEEPING IN MIND THEY OPEN IN NEW TABS OR WINDOWS. -AI

GUIDES FOR FORMS & SUBMISSIONS -AI

THESE GUIDES COVER FEEDBACK FORMS, CONTACT FORMS, AND OTHER PLACES WHERE YOU CAN SUBMIT INFORMATION, REQUEST PRAYER, OR SHARE TESTIMONIES. -AI

USING THE MAIN FEEDBACK FORM -AI

  1. VISIT THE FEEDBACK & SUGGESTIONS PAGE: OPEN FEEDBACK PAGE -AI
  2. CLICK THE LINK TO OPEN THE MULTI-PAGE FEEDBACK FORM (USUALLY HOSTED VIA GOOGLE FORMS). -AI
  3. READ EACH PAGE TITLE TO SEE WHAT KIND OF FEEDBACK IT COVERS (OVERALL EXPERIENCE, BUGS, FEATURE REQUESTS, ETC.). -AI
  4. ANSWER ONLY THE QUESTIONS THAT APPLY TO YOU; YOU CAN SKIP OTHERS. -AI
  5. SUBMIT THE FORM WHEN FINISHED; IF YOU WANT A RESPONSE, INCLUDE AN EMAIL ADDRESS WHERE REQUESTED. -AI

SUBMITTING PRAYER REQUESTS OR TESTIMONIES (WHEN AVAILABLE) -AI

  1. GO TO THE PRAYER, TESTIMONIES & BLESSINGS PAGE: OPEN PRAYER & TESTIMONY PAGE -AI
  2. READ ANY NOTES ABOUT HOW SUBMISSIONS ARE USED, SHARED, OR KEPT PRIVATE. -AI
  3. USE THE PROVIDED FORM OR LINKED TOOL TO SHARE YOUR REQUEST OR STORY. -AI
  4. IF THERE ARE OPTIONS FOR PUBLIC OR PRIVATE SHARING, CHOOSE WHATEVER FEELS MOST APPROPRIATE FOR YOU. -AI

GUIDES FOR EXPORTS & DOWNLOADS -AI

SOME TOOLS ALLOW YOU TO EXPORT DATA (SUCH AS WORD LISTS OR STUDY NOTES) TO A FILE FORMAT LIKE CSV, WHICH YOU CAN OPEN IN A SPREADSHEET OR OTHER PROGRAM. -AI

GENERAL PATTERN FOR EXPORTING A CSV FILE -AI

  1. LOOK FOR AN “EXPORT” OR “DOWNLOAD CSV” BUTTON NEAR THE TOOL’S OUTPUT AREA. -AI
  2. IF THERE IS AN INFO ICON (SUCH AS A “?”) NEXT TO THE BUTTON, CLICK IT TO SEE WHAT THE EXPORT WILL CONTAIN AND HOW COLUMNS ARE LABELED. -AI
  3. CLICK THE EXPORT BUTTON AND WAIT FOR THE FILE TO DOWNLOAD. BROWSERS USUALLY SHOW THE FILE NEAR THE BOTTOM OF THE WINDOW OR IN A DOWNLOADS PANEL. -AI
  4. OPEN THE FILE IN A SPREADSHEET PROGRAM (SUCH AS EXCEL, GOOGLE SHEETS, OR LIBREOFFICE CALC) TO VIEW OR EDIT THE CONTENT. -AI
  5. SAVE OR ORGANIZE THE FILE IN A FOLDER WHERE YOU CAN EASILY FIND IT FOR FUTURE STUDY. -AI

FUTURE EXPANSION: ADD TOOL-SPECIFIC EXPORT GUIDES (FOR EXAMPLE, HOW TO USE A PARTICULAR WORD LIST OR STUDY EXPORT IN OTHER PROGRAMS). -AI
