Infinite Bible – unified Bible & Notes (boards)

Infinite Bible is a single workspace that can host both Bible chapter boards and free-form note boards. Everything shares the same storage and tools so you only have to learn one interface.

Your data is stored locally in your browser (no account, no sync) in this early version.

Bible mode

  • Each board represents a single chapter in a specific translation.
  • Boards can hold verse blocks, notes, highlights, and more.
  • Navigator will list books and chapters for the active translation.

Notes mode

  • Named boards for topics, projects, or sermon prep.
  • Boards will be able to mix verses from any chapter with your notes.
  • Notes mode will share the same tools, navigation, and storage.
  • Boards only persist if you add your own content (notes, highlights, etc.).

Using this prototype

This is an early layout prototype. The toolbar, navigator, and workspace shell are present so we can refine the experience on both desktop and mobile before wiring up real Scripture data and board interactions.

  • Use the Navigator button to show or hide the left panel.
  • Use the Theme toggle to switch the canvas between light and dark.
  • As the tool develops, boards will store layout and notes locally in your browser.
