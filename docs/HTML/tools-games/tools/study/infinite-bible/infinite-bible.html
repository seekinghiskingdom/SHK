Infinite Bible (Tool)

A visual Bible workspace for reading, studying, and mapping Scripture, with two modes: Infinite Bible (Bible Mode) and Infinite Bible Notes (Notes Mode).

Open Bible Mode Open Notes Mode

Early version: all boards and layouts are stored locally in your browser on this device. No accounts, no sync yet.

Choose how you want to study

Infinite Bible (Bible Mode)

Chapter-based reading and study, in a single “Infinite Bible” workspace.

  • Start from a blank Bible board and load chapters as you need them.
  • Each chapter appears as a structured layout of verses you can rearrange and annotate.
  • Only the chapter you are working in needs to stay open, so performance stays manageable.
  • Use notes and spacing to build visual chapter maps, proverb webs, and exegesis layouts.

Infinite Bible Notes (Notes Mode)

Free-form boards for verses, notes, themes, and connections.

  • Create multiple named boards for topics, projects, or sermons.
  • Insert any passage or verse by reference; drag blocks around a large canvas.
  • Add notes directly beside the text to capture questions, observations, and cross-links.
  • Use boards for thematic studies, Proverbs pairs, counseling notes, or teaching prep.

Quick start

Quick start in Bible Mode

  1. Open Bible Mode.
  2. Select a book and chapter (for example, Proverbs 1) and click Load Chapter.
  3. Optionally choose to split into one block per verse and whether to include verse numbers.
  4. Drag verses and notes to group ideas, mark contrasts, or build a visual outline.
  5. Load more chapters over time; use the chapter list to jump between them.

Quick start in Notes Mode

  1. Open Notes Mode and create a new board (e.g., “Proverbs Pairs” or “Sermon – James 1”).
  2. Click Insert passage and type a reference (for example, “Proverbs 1:7–9”).
  3. Choose whether to make each verse its own block and whether to include verse numbers.
  4. Add notes around the verses to record insights, questions, and links to other passages.
  5. Repeat on other boards for different topics or projects as needed.

Details and roadmap

How data is stored
  • Local only: In v1, all boards live in your browser’s storage on this device.
  • Per-device: Using another browser or device gives you a separate set of boards.
  • Clearing data: Clearing browser storage or using private browsing can remove saved boards.
  • Future plans: Export/import, and eventually optional cloud sync, are planned for later versions.
What Bible Mode is designed for

Bible Mode is built for chapter-based study where you want to stay inside one continuous Bible workspace instead of jumping between separate tools.

  • Devotional reading with notes layered directly on the chapter.
  • Word-level or verse-level layouts (especially in books like Proverbs or Romans).
  • Side-by-side chapter comparisons over time (e.g., revisiting the same chapter in different seasons).

Under the hood, chapters are loaded on demand so you do not have to load the entire Bible at once. Only the active chapter needs to be expanded at any given time.

What Notes Mode is designed for

Notes Mode is intentionally flexible. Each board is a blank canvas for Scripture and notes, without forcing a single pattern of study.

  • Topical studies (e.g., “Humility,” “Justice,” “Prayer in the Psalms”).
  • Proverb pair mapping and virtue webs.
  • Sermon or teaching planning with supporting passages around a central text.
  • Personal journaling with verses and reflections connected visually.
Planned future features
  • Export and import of boards as files.
  • Stickers and markers (e.g., “!”, “?”, cross-links) around verses and notes.
  • Bookmarks and table-of-contents views per board or per Bible Mode chapter set.
  • Template boards (for example, “Chapter template,” “Sermon prep template,” “Random verse starter”).
  • Optional accounts and sync when dynamic infrastructure is available.

Which mode should I use?

  • Use Bible Mode when you want one continuous Bible workspace, organized primarily by book and chapter.
  • Use Notes Mode when you want multiple separate boards for themes, projects, or experiments.
  • You can switch between modes at any time; they are separate views built on the same underlying Scripture data.
