Infinite Bible

Bible Mode

Work through Scripture one chapter at a time in a single visual Infinite Bible workspace.

How to use (current beta)

  • This page will become the main “Bible board” for chapter-based study and layouts.
  • Upcoming steps will let you load chapters, see them as blocks, and add notes nearby.
  • All layouts and notes will be stored locally in your browser on this device.

Early work in progress

  • Bible Mode is still under construction; features may change as Infinite Bible develops.
  • Text formatting, canvas behavior, and tools for notes and connections will evolve.
  • If something feels off, you can always fall back to the main Bible Viewer for now.

Tips & notes

  • Use Bible Mode for chapter-based layouts you want to revisit and refine over time.
  • Use Notes Mode for free-form topic boards, Proverbs webs, and sermon outlines.
  • Nothing is synced yet; everything lives only in the browser where you use it.
