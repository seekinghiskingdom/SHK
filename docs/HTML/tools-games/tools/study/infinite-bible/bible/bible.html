Infinite Bible

Bible Mode

Work through Scripture one chapter at a time in a single visual Infinite Bible workspace.

How to use (current beta)

  • This page will become the main “Bible board” for chapter-based study and layouts.
  • In the next steps, you’ll be able to load chapters, see them as blocks, and add notes nearby.
  • All layouts and notes will be stored locally in your browser on this device.

Early work in progress

  • Bible Mode is still under construction; features may change as Infinite Bible Notes matures.
  • Text formatting, canvas behavior, and tools for notes and connections will improve over time.
  • If something looks broken or confusing, you can always fall back to the main Bible Viewer for now.

Tips & notes

  • Use Bible Mode when you want a chapter-based visual layout that you can revisit later.
  • Use Notes Mode when you want free-form boards for topics, Proverbs pairs, or sermon outlines.
  • Remember that nothing is synced yet; everything lives only in the browser where you use it.
