Infinite Bible (Tool) · Bible Mode

Infinite Bible – Bible Mode

Load chapters one at a time into a single Bible workspace, customize each chapter, and move back and forth as you study.

Bible Mode Notes Mode

Early version: all layouts and notes are stored locally in your browser on this device only.

Chapter Controls

Bible Mode treats all chapters as part of one “Infinite Bible” board. Only the active chapter has to be open at once.

Chapters in this Bible board

Click a chapter to jump to it. Chapters can be collapsed to keep the workspace manageable.

Bible board

How to use Bible Mode

  1. Select a book and chapter, then click Load Chapter.
  2. Use the canvas tools to pan, move verses, and add notes in that chapter.
  3. Load new chapters as you go; use the chapter list on the left to jump between them.
  4. Your layout and notes are saved locally and restored next time on this device.
